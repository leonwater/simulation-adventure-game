# 모험가 키우기

한 명의 모험가를 오래 키워 던전 최하층(1차 30층)을 정복하는 **모바일 텍스트 시뮬레이션 RPG**입니다.
Unity로 만든 앱 게임(Android·iOS, 세로 화면)이며, 기획서와 UI 시안을 바탕으로 개발했습니다.

## 바로 열기

1. **Unity 6 (6000.0 LTS)** 를 설치합니다. 기기 빌드를 하려면 Android Build Support(또는 iOS Build Support) 모듈도 함께 설치합니다.
2. Unity Hub → **Add project from disk** → 이 저장소 폴더를 선택합니다.
3. 처음 열면 `Assets/Scenes/Main.unity`가 자동으로 생성되고 빌드 씬·앱 이름·세로 화면이 설정됩니다.
   (다시 적용하려면 메뉴 **모험가 키우기 → 프로젝트 설정 다시 적용**)
4. `Main` 씬을 열고 ▶ 재생. Game 뷰 해상도를 **390 × 844**(또는 아무 세로 비율)로 맞추면 시안과 같은 화면이 나옵니다.

> 화면은 프리팹 없이 코드(uGUI)로 만들어지므로 씬에는 카메라만 있습니다. 실행하면 `GameApp`이 자동으로 생성됩니다.

### 기기 빌드

- **Android**: File → Build Profiles(Build Settings) → Android → Switch Platform → Build.
- **iOS**: iOS로 전환 → Build → 생성된 Xcode 프로젝트에서 서명 후 실행.
- 패키지 이름 `com.leonwater.adventurer` (에디터 설정 스크립트 `Assets/Scripts/Editor/ProjectSetup.cs`에서 변경).

### APK 자동 빌드 (GitHub Actions)

`main`에 게임 파일(`Assets`·`Packages`·`ProjectSettings`)이 바뀌어 올라오면 APK가 자동으로 만들어집니다.
Actions 탭 → **Android APK 빌드** → **Run workflow**로 직접 실행할 수도 있습니다.

- 결과: 저장소 **Releases → 최신 APK (android-latest)** 의 `adventurer.apk` (휴대폰에서 바로 받기)
- 처음 한 번 저장소 **Settings → Secrets and variables → Actions**에 비밀값 3개를 등록해야 합니다.
  - `UNITY_LICENSE`: Unity Hub로 로그인한 PC의 `Unity_lic.ulf` 파일 내용 전체
    (Windows `C:\ProgramData\Unity\Unity_lic.ulf`, Mac `/Library/Application Support/Unity/Unity_lic.ulf`)
  - `UNITY_EMAIL`, `UNITY_PASSWORD`: Unity 계정
- **업데이트 설치용 서명 키 (권장)**: `ANDROID_KEYSTORE_BASE64`·`ANDROID_KEYSTORE_PASS`·`ANDROID_KEYALIAS_NAME`·`ANDROID_KEYALIAS_PASS`를 넣으면
  빌드마다 같은 키로 서명되어 새 버전을 기존 앱 위에 바로 덮어 설치할 수 있습니다 (저장 유지).
  없으면 빌드마다 디버그 키가 달라 업데이트 때 기존 앱을 지우고 설치해야 합니다 (저장 데이터도 지워짐).
  키 만들기: `keytool -genkeypair -keystore adventurer.keystore -alias adventurer -keyalg RSA -keysize 2048 -validity 20000`
  → `base64 -w0 adventurer.keystore` 결과를 `ANDROID_KEYSTORE_BASE64`에, 비밀번호를 `_PASS` 두 곳에, `adventurer`를 `_NAME`에.
  키 파일과 비밀번호는 잃어버리면 같은 앱으로 업데이트할 수 없으니 따로 보관하세요.
- 버전 코드는 Actions 실행 번호로 매번 커집니다 (업데이트 설치 조건).
- 빌드 스크립트: `Assets/Scripts/Editor/CIBuild.cs`, 워크플로: `.github/workflows/android-build.yml`

## 화면 (UI 시안 + 수정 사항 27개 반영, 기획서 v1.2)

시작(시작하기·이어하기 요약·설정·종료) · 프롤로그 · 길드 등록(이름→직업→난이도→확인) · 마을(시설 2×2 아이콘 카드) ·
길드(퀘스트·등급·창고) · 상점(3열 카드) · 대장간 · 수련장 · 캐릭터 · 가방·장비 · 스킬 · 설정 ·
던전 탐험(테마 색 미니맵·전체 지도) · 전투(도형 무대·연출) · 특수 이벤트 · 정산(패배 비교표·귀환·엔딩)

- 튜토리얼(직접 해 보기): 화면 한 곳만 밝게 남기고 말풍선으로 안내(코치 마크). 상점·길드·대장간·수련장에 직접 들어가 부분별 설명 → 던전 입장 → 고정 1층(미니맵·길 선택·전투·레벨 업) → 귀환 후 정산·창고.
  튜토리얼 중에는 안내한 곳과 건너뛰기만 눌리고, 첫 던전에서는 가방·도주·타이틀로 가기를 잠근다. 건너뛰기는 이 기기에서 튜토리얼을 한 번 끝까지 마친 뒤부터 나온다. 설정에서 다시 보기.
- 전투: 내 원형(왼쪽, 누르면 캐릭터 정보), 적 최대 4(일반 사각형·엘리트 굵은 테두리·보스 육각형, HP 숫자 표시). 적을 눌러 대상 선택, 선택지 아래 예상 피해, 길게 누르면 피해 계산식·부가 효과·성공 확률 내역.
  상태 이상은 도형 아래 아이콘 16종(테두리 푸른색 이로움·붉은색 해로움, 1턴 남으면 천천히 깜빡임), 이름·남은 턴은 상세 창에.
  성공률: 기본 공격 81%(62~92%)이 가장 높고, 위력 낮은 스킬 −3~5% · 높은 스킬 −8~12%. 도주 67%(최대 87%).
  스킬은 등급이 높을수록 기본 피해가 크고, 수련 1단계마다 하급 +8% · 중급 +10% · 상급 +12% · 최상급 +15%.
  도적: 스킬 피해는 다른 직업의 80%, 치명타 ×2.3, 약점 간파(예리함: 스킬 치명타 확률 +25%)·살의(잔혹함: 치명타 피해 +50%).
- 보스 특성 11종(방어막·보호막·가시 비늘·혼신의 일격·연속 공격·흡혈·광폭화·분열·재생 의식·부활·부하 소환), 층이 깊을수록 강해짐. 다음 턴 행동은 이름 자리에 주황색 '!'로 예고.
- 던전: 미니맵 방 아이콘, 미니맵 오른쪽 아래 지도 버튼(전체 지도·순간이동), 이벤트로 공개된 방은 흐리게·연쇄 이벤트 방은 "!", 탐험 효과 태그.
  방 결과(보물·휴식·전투·이벤트)는 카드로 먼저 크게. 하단은 가방 · 캐릭터 정보(상태 이상 1턴 피해 등) · 귀환(귀환 방 미발견 시 붉은 회색).
  이동은 금색·푸른색, 귀환은 초록, 방 안 행동은 보라색. 튜토리얼 던전은 보스를 잡아도 아래층으로 못 내려가고 귀환.
- 가방·창고: 4열 격자, 종류별 색 원(무기·방어구·장신구·소모품·기타·스킬서·강화석), 장비 종류는 무기·방어구(투구·갑옷·바지·장화)·장신구(목걸이·반지)로 묶어 표시,
  등급 색 이름·착용 레벨·지금 장비 대비 수치, 스킬서는 등급 · 쓸 수 있는 직업(다른 직업이면 빨강). 칸을 누르면 화면 가운데 팝업(정보·착용/교체·사용·판매).
  반지는 빈 칸 → 덜 중요한 반지(직업 주요 능력치가 아닌 쪽, 같으면 수치 낮은 쪽) 순으로 바꾸고, 칸의 증감도 같은 기준으로 보여 준다.
- 상점: 판매 칸에도 지금 장비 대비 증감·스킬서 직업 표시. '선택 판매'(또는 카드 길게 누르기)로 여러 칸을 한 번에, '일괄 판매'로 기타 아이템을 한 번에 판매. 강화한 장비는 강화 골드의 50%를 더 받는다. 배운 스킬의 스킬서는 살 수 없다.
- 가방 확장: 가방 화면의 + 버튼 → 확인 창에서 바로 구매 (상점에는 없음).
- 길드 창고: 보관(기본)/출고 탭, 맡길 때만 수수료 10 + 돌파 층 × 5 G (접수원이 안내). 던전 상인은 물건마다 재고 2~5개, 거래 창은 처음 들어갈 때만 자동으로 열린다.
- 장비 (v2.0): 적정 장비(1~11층 고급 · 12~19층 희귀 · 20층~ 영웅, 강화 층 ÷ 2)에서도 무기는 공격력의, 방어구는 받는 피해의, 장신구 3개는 주 능력치의 40%를 넘지 않는다 (`GameBalance.MaxGearShare`, 테스트로 고정).
  공격력 = 주 능력치 × 5 + 무기, 피해 × 400/(400 + 방어력). 기본 수치는 착용 레벨이 주로 정하고(무기 6 + Lv × 2 등) 등급 배율은 1.0·1.07·1.14·1.21·1.28이라 레벨 차이가 크면 낮은 등급이라도 높은 레벨 장비가 앞선다.
  강화 최대 +15, 단계마다 등급별 +2·2.5·3·3.5·4% (무기·방어구 최소 +1, 장신구 2단계마다 최소 +1). 예전 저장의 장비 수치는 불러올 때 새 공식으로 바뀐다.
  드롭·상점 장비와 스킬서는 내 레벨보다 높게 나오면 절반 확률로 다시 정하고, 내 레벨보다 낮은 장비는 10% 확률로 한 등급 위.
  강화 성공률 100·100·100·95·90·80·70·60·50·40·30·25·20·15·10%, +6부터 강화석, +7 이상 실패 시 30%(+11부터 50%) 확률로 한 단계 하락.
  비용 = 30 × 목표 단계 × (1 + 착용 레벨 ÷ 10) × 등급 배율(1.0·1.3·1.7·2.2·3.0). 강화석은 10층부터 나온다 (적정 강화 = 층 ÷ 2, +6이 적정인 12층의 2층 앞).
  대장간 장비 고르기는 가방의 장착 장비 칸과 같은 4열 칸: 장착 장비(부위 순서) → 가방 장비.
- 장비·스킬서는 지금 직업 70% · 다른 직업 각 10%. 보스는 특성마다 HP·공격력·방어력이 다르다.
- 모험가 등급: 'D 등급 모험가'처럼 표시. 조건을 모두 채우면 자동 승급 + 알림 창 (등급 효과·스킬 칸·창고 칸 바로 적용).
- 능력치 최대값: 모두 99 (최대 레벨 60). 캐릭터 화면은 배분한 값과 이름 옆 장비·등급 효과 추가분 (+N)을 보여 준다 (45/99 표시는 삭제).
- 등록: 난이도는 이름과 추천 대상만, 확인 화면 직업은 '직업 [아이콘] 전사'까지.
- 피의 우물: 바칠 때마다 공포·저주·추가 출혈 중 하나가 붙을 확률 10 → 20 → 35 → 50 → 65%.
- 던전 밖 모든 화면의 머리줄 오른쪽은 골드(10만부터 '12.3만'처럼 줄여 씀) + 설정 버튼. 하단 메뉴는 아이콘(마을·캐릭터·가방·스킬북).
- 던전 색: 새 방 금색 · 탐험한 방 푸른색 · 귀환 초록 · 방 안 행동 보라 · 아래층 진홍, 방 결과·설명 카드는 중립색. 특수 이벤트는 일러스트 없이, 보상·횟수는 숨긴다. 마을 머리줄은 이름·직업·배지 / Lv.·경험치, 마을 이름 옆 난이도 색(쉬움 파랑·보통 초록·어려움 주황·하드코어 빨강).
- 화면 비율: 폭 390 기둥, 최소 높이 700 (`ScreenFit`). 16:9~21:9 휴대폰은 폭에 맞추고, 폴더블·태블릿처럼 넓은 화면은 가운데 기둥. 노치는 안전 영역으로 피한다.
- 특수 이벤트 34개 (기획서 v1.5: 연쇄·지도 공개·보물 더미·피의 우물·스핑크스·운명의 카드·시련의 문 등).
- 설정: 마을 오른쪽 위 톱니바퀴 → 설정 창. 기기 설정(PlayerPrefs): 전투 속도 1×/2×, 대사 한 글자씩, 진동, 글자 크기 3단계.
- 알림 점: 남은 능력치 포인트, 새 스킬, 완료 퀘스트, 상점 갱신.
- 일러스트: 마을(`town.jpg`)·길드(`guild_receptionist.jpg`)·대장간(`blacksmith.jpg`)·수련장(`training.jpg`)·상점(`shop.jpg`) 적용. 나머지는 점선 상자로 표시됩니다.
  그림은 원본 비율을 유지한 채 잘라 채웁니다 (`Assets/Scripts/Editor/AssetImportRules.cs`가 2의 거듭제곱 늘림을 끄고 압축).

- 아이콘: `Assets/Resources/Icons/` — 하단 메뉴 4종(nav_*), 시설 4종, 등급 배지 8종(rank_f~rank_ss), 능력치 10종(stat_*), 강화석, 가방, 귀환, 지도, 캐릭터, 설정, 골드, 더하기, 직업 4종(job_*), 미니맵 방 8종(room_*), 상태 이상 16종(status_*).

2. Core를 Unity와 같은 .NET Standard 2.1 / C# 9로 컴파일
3. 전체 스크립트를 Unity 참조 어셈블리로 컴파일 (기기 빌드 조건 / 에디터 조건)

필요한 것: .NET 8 SDK, `api.nuget.org` 접속 (Unity 참조 어셈블리를 NuGet에서 내려받음).

밸런스 확인: `tools/balance/run.sh` (보통·어려움 진행 속도), `run.sh fight` (층별 전투 HP 소모), `run.sh boss` (보스 특성 켬/끔 비교).
Unity 에디터에서는 Window → General → Test Runner → EditMode에서 같은 테스트를 실행할 수 있습니다.

## 저장

- 기기의 `Application.persistentDataPath/save.json` (직전 저장은 `.bak`로 보관).
- 방을 하나 끝낼 때마다, 마을에서 행동할 때마다, 앱이 백그라운드로 갈 때 자동 저장합니다.
- 전투 중에 앱을 끄면 다시 켰을 때 그 방의 전투를 처음부터 다시 시작합니다.
- 앱을 업데이트한 뒤 예전 던전 진행을 이어 갈 수 없으면(데이터가 바뀌어 오류) 캐릭터는 그대로 두고 마을에서 시작합니다.
