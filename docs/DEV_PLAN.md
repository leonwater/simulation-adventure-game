# 모험가 키우기 — 개발 작업 기획

기획서(`모험가 키우기 기획서`, 2026-10-17)와 UI 시안(11개 화면)을 바탕으로 한 Unity 모바일 앱 개발 계획입니다.

## 1. 목표

- Unity(uGUI) 기반 **모바일 앱**(Android/iOS, 세로 화면). 웹 빌드 아님.
- 1차 범위: 던전 30층, 직업 4종, 화면 11종 + 대장간·수련장·설정.
- 모든 수치는 임시값이며 `GameBalance.cs` 한 곳에 모아 밸런싱에서 조정합니다.

## 2. 구조

| 계층 | 위치 | 내용 |
| --- | --- | --- |
| Core | `Assets/Scripts/Core` | 순수 C# 게임 로직. UnityEngine 참조 없음(`noEngineReferences`). 단위 테스트 대상 |
| Game | `Assets/Scripts/Game` | Unity 런타임. 부트스트랩, 코드로 생성하는 uGUI 화면, 저장 파일 입출력 |
| Editor | `Assets/Scripts/Editor` | 프로젝트 자동 설정(메인 씬 생성, 빌드 씬 등록, 세로 화면·앱 이름 등) |
| Tests | `Assets/Tests/EditMode` | NUnit 테스트. Unity Test Runner와 `dotnet test` 양쪽에서 실행 |
| Verify | `tools/verify` | Unity 없이 검증: Core 테스트 + Unity 참조 DLL 대상 전체 컴파일 검사 |

화면은 프리팹 없이 코드로 만들어 씬·프리팹 병합 충돌이 없고, 어떤 환경에서든 저장소만 받으면 바로 열 수 있습니다.

> §3~§6은 처음 계획(2026-10-18 기준)이라 숫자·화면 구성이 지금과 다릅니다. 최신 규칙은 §7 이후 업데이트와 기획서를 보세요.

## 4. 기획서에서 비어 있어 임시로 정한 것

기획서에 수치나 규칙이 없는 부분은 아래처럼 정했습니다. 모두 `GameBalance.cs`에서 바꿀 수 있습니다.

| 항목 | 임시 규칙 |
| --- | --- |
| 필요 경험치 | 100 × 레벨^1.5 (이전 기획서 값) |
| 사망 시 경험치 −20% | 현재 레벨 필요 경험치의 20%를 잃되 0 아래로 내려가지 않음 |
| 시작 능력치 | 전 능력치 5, 직업 주력 3종 +3 |
| 피해 공식 | 공격력 × 배율 × 100 / (100 + 방어력) × (1 − 강인함 감소율) |
| 공격 성공률 | 50% + (주 공격 능력치 − 적 요구치) × 5% + 정밀 보정, 5~95% |
| 적 피격 확률 | 90% − 회피(민첩 × 0.5%) |
| 스킬 강화 | 최대 +5, 단계당 위력 +10% |
| 강화석 | +6~+8은 1개, +9~+10은 2개 필요. 던전 드롭 |
| 퀘스트 종류 | 토벌(특정 몬스터 처치), 채집(재료 수집), 정복(층 보스 처치) |
| 휴식 방 | 최대 HP 40% 회복 + 디버프 해제 |
| 자동 저장 | 방 하나를 끝낼 때마다, 마을 행동마다, 앱이 백그라운드로 갈 때 저장 (플레이 테스트 후 조정) |
| 30층 보스 처치 | 엔딩 화면 표시 후 계속 플레이 가능 |

## 45. v3.7 직업 재정비·화면 손질 (2026-11-01)

사용자 결정: 도적 고유 = 치명타 확률·피해 둘 다 조금씩(낮게), 궁수 고유 = 회피 → 기본 공격 관통, 재사용 대기는 던전 안에서만 이어짐(마을에서 초기화), 스킬 '마력 폭주' → '마력 해방'(디버프 이름이 '마력 폭주').

- 직업
  - 도적: 관통 삭제(예전 치명타로 되돌림). 고유 '급소'(가칭) = 치명타 확률·피해 소폭 증가.
  - 궁수: 기본 공격이 주력. 고유 '관통' = 기본 공격이 방어 20→50% 무시. 기본 피해 수치는 다른 직업보다 낮게, 기본 공격 명중은 높게(저점 높음). 스킬은 기본 공격 강화(피해↑·2회 타격·방어 무시↑)·광역 위주, 재사용 대기는 보통(잦은 스킬 콘셉트 삭제).
  - 마법사: 기본 공격 자리에 '에너지 볼'(단일, 무기 공격력·등급 비례, 특수 효과 없음, 재사용 2턴). 쓸 수 있는 공격이 하나도 없으면 '마력 폭주'로 억지로 쏘고 몇 턴간 주는 피해↓·받는 피해↑.
  - 단단함: 마법사 < 도적 = 궁수 < 전사 (도적 HP 계수 9 → 10).
  - 스킬 재사용 대기가 전투가 끝나도 이어짐 (같은 던전 안, 마을에서 초기화, 저장됨).
  - 바뀐 점은 튜토리얼·도움말에 표기. 직업 선택 확인 창과 캐릭터 등급 카드를 누르면 직업 상세(고유 능력치·등급별 상승량·주요 능력치, 다른 직업과 비교하거나 공략성 정보는 없음). 직업 칸에 난이도(전사 쉬움 · 궁수·도적 보통 · 마법사 어려움).
- 화면
  - 상점: 물건 갱신을 화면 아래 고정 줄로(목록과 겹치지 않음). 스킬 장착 칸은 3×2로 되돌림, 드래그로 순서 바꾸기 확인·강화 단계 표시가 카드 밖으로 나가지 않게.
  - 의뢰 게시판 밝기를 다른 화면과 비슷하게, 포기 버튼이 종이와 구분되게. 바탕(화면 배경)이 픽셀풍에 어울리는지 다시 점검.
  - 대장간: 강화 버튼의 장비 그림 대신 '강화' 아이콘(claude-pxl), 강화 결과 연출이 누른 버튼에서 시작.
  - 버그: 일괄 판매가 안 눌림, 설정 버튼 누를 때마다 깜빡임.
- 밸런스: 바뀐 직업으로 시뮬레이션 다시(보통 150회 × 3시드), 사망률이 v3.5 수준(30~40%대, 21~30층 60%대)이 되게 조정.
- 결과: 위 계획 모두 반영. 밸런스(보통, 150회 × 3시드): 사망률 34·30·31·35·52·58%, 30층 정복 2/12 (v3.5 36·33·39·37·60·61% 수준). 직업별로 전사가 가장 쉽고 마법사가 초반 도전 횟수·사망이 가장 많아 난이도 표시(전사 쉬움·마법사 어려움)와 맞음. 에너지 볼은 무기 공격력만으로는 초반에 너무 약해(봇이 3층도 못 넘음) '공격력 × (0.8 + 무기 등급당 0.1) + 무기 공격력'으로 정함. 궁수 강화 스킬 지속은 기존 규칙(비전투 0단계 2턴)에 맞춰 2턴. 드래그 순서 바꾸기는 마우스·터치 모두 동작 확인(눈에 띄게 손잡이 추가). 설정 깜빡임 원인: 값을 고를 때마다 창을 닫고 화면 전체를 다시 그리던 것. 테스트 215개, 화면 점검 40화면 × 3폭 문제 0건.

## 46. v3.8 직업 정보 정리·마력 폭주 피하기 (2026-11-02)

사용자 결정: 마력 폭주는 '에너지 볼 재사용 1턴 + 하급 스킬 재사용 단축'으로 피한다 (긴 스킬만 끼면 폭주가 날 수 있음은 받아들임).

- 직업 선택: 난이도를 장단점과 떨어진 칸 오른쪽 위 꼬리표로(파란 칸 1~3개 + 이름), 장단점은 점선 아래 초록 +/주황 −.
- 직업 정보 창: 줄글 대신 요점 표(주요 능력치·HP·기본 공격·시작 스킬, 마법사는 마력 폭주 한 줄) + 고유 능력치 상자(아이콘·이름·한 줄 요점·등급별 값).
- 저항 표기: 좁은 칸(레벨 업 창·캐릭터 능력치 줄)은 '저항', 상세 능력치·캐릭터 정보 창은 '상태 이상 저항'. 화면 점검에 큰 능력치(소수·두 자리 %)의 레벨 업 창·상세 능력치를 추가.
- 마력 폭주: 에너지 볼 재사용 2 → 1턴, 화염구 3 → 1턴(180 → 130% + 화상), 마력 화살 2 → 1턴(120 → 140%), 불꽃 파편 4 → 3턴. 화염구·마력 화살 중 하나라도 끼면 에너지 볼과 번갈아 써서 끝까지 폭주 없음(시작 스킬 = 화염구라 튜토리얼도 해당). 침묵에 걸리면 스킬을 못 써 예외.
- 캐릭터 등급 카드: 고유 능력치는 아이콘 · 지금 값 → 다음 등급 값만, 승급 조건은 굵은 칸 3개(채우면 초록).
- 고유 능력치 설명의 '(대신 재사용 대기가 김)' 같은 단서 삭제.
- 상세 능력치·캐릭터 정보·적 정보 창의 능력치에 아이콘.
- 창고: 창고·가방 남은 칸 표시, 출고 화면에 창고 빈칸.
- 던전 가방: '던전으로 돌아가기' 버튼 가운데.
- 결과: 위 계획 모두 반영. 마법사 밸런스(보통, 150회 × 3시드): 사망률 43·42·36·58·64% (v3.7 38·31·27·37·66%, 시드 3개라 흔들림이 큼) — 10층 돌파는 평균 45회째로 v3.7(62회째)보다 빨라졌고 11~20층은 조금 어려워짐. 테스트 216개(모든 마법사 조합 폭주 회피 테스트 추가), 화면 점검 42화면 × 3폭.
