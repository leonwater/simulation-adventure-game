# 모험가 키우기 기획서

2026-10-17 · 재헌

> 이 파일은 처음(v1.0) 기획서의 사본입니다. 최신 기획서(v2.x)는 Claude Docs의 "모험가 키우기 기획서"이며, 개발에서 바뀐 내용은 `docs/DEV_PLAN.md`에 있습니다.

## 게임 개요

모바일용 텍스트 기반 모험가 육성 게임입니다. 처음 정한 직업으로 한 캐릭터를 장기간 키워 던전 최하층을 클리어하는 것이 최종 목표입니다.

| 항목 | 내용 |
|---|---|
| 장르 | 장기 육성형 텍스트 RPG |
| 플랫폼 | 모바일 (세로 화면) |
| 수익 모델 | 유료 판매 |
| 개발 범위 | 1차 30층으로 개발 후 업데이트로 층 확장 |
| 직업 | 전사, 궁수, 도적, 마법사 (추후 확장). 게임 시작 시 결정하며 변경 불가 |
| 핵심 루프 | 마을(수련장·상점·대장간·길드) → 던전 탐험 → 귀환 → 성장 |
| 마을·특수 이벤트 화면 | 상단 일러스트 + 하단 텍스트·선택지 |
| 던전 탐험·전투 화면 | 일러스트 없이 텍스트와 기본 도형만으로 진행 상황(HP, 적, 미니맵)을 보여주는 단순한 화면 (예: 스트라이커 키우기) |
| 인게임 시간 | 없음 (v2.4부터 상점도 자동 갱신 없음) |
| 밸런싱 원칙 | 확률·재고·비용 등 모든 수치는 임시값이며 추후 밸런싱에서 조정 |

## 캐릭터

능력치는 하나의 목록으로 통합하고, 직업 특화 능력치는 단순하면서 직업 특성이 드러나도록 구성합니다. 플레이어 화면에는 자기 직업이 주로 쓰는 능력치만 간략히 보여줍니다.

### 능력치 목록

| 능력치 | 주 사용 직업 | 효과 | 임시 공식 |
|---|---|---|---|
| 체력 | 공통 | 최대 HP 증가 | HP = 50 + 체력 × 10 |
| 정신 | 공통 | 디버프 저항 | 저항 = 정신 × 1% |
| 행운 | 공통 | 치명타 확률, 드롭률 증가 | 치명타 = 5% + 행운 × 0.3% |
| 힘 | 전사 | 물리 공격력 증가 | 공격력 = 힘 × 2 + 무기 |
| 민첩 | 궁수, 도적 | 공격력, 회피, 도주 성공률 증가 | 회피 = 민첩 × 0.5% |
| 지능 | 마법사 | 마법 공격력 증가 | 공격력 = 지능 × 2 + 무기 |
| 강인함 | 전사 | 받는 피해 감소 | 감소율 = 강인함 × 0.35%, 최대 30% (v2.4) |
| 정밀 | 궁수 | 공격 성공률 증가 | 성공률 + 정밀 × 0.5% |
| 급소 | 도적 | 치명타 시 피해 증가 | 치명타 피해 = 150% + 급소 × 1% |
| 주문력 | 마법사 | 스킬 피해 증가 | 스킬 피해 + 주문력 × 1% |

### 화면 표시 (간략 능력치)

| 직업 | 기본 화면에 보이는 능력치 |
|---|---|
| 전사 | 체력, 힘, 강인함 |
| 궁수 | 체력, 민첩, 정밀 |
| 도적 | 체력, 민첩, 급소 |
| 마법사 | 체력, 지능, 주문력 |

상세 보기 버튼을 누르면 전체 능력치를 볼 수 있습니다.

### 레벨업과 능력치 배분

- 레벨업마다 능력치 포인트 3을 지급합니다 (임시).
- 직업 변경이 없으므로, 포인트는 자기 직업의 주력 능력치(간략 화면 3개)와 공통 능력치(정신, 행운)에만 배분할 수 있습니다.
- 플레이어가 직접 배분하거나 자동 배분 버튼을 누릅니다.
- 자동 배분은 직업별 비율로 나눕니다. 예: 전사 힘 40% · 체력 30% · 강인함 20% · 행운 10% (임시).
- 레벨은 내려가지 않습니다. 사망으로 경험치가 줄어도 현재 레벨의 0까지만 감소합니다.

최대 레벨은 60입니다 (1차 30층 기준, 임시).

## 스킬

스킬은 액티브만 존재하고, 패시브 효과는 버프로 처리합니다. 자원은 소모하지 않으며 스킬마다 재사용 대기 턴이 있습니다.

### 획득과 강화

| 경로 | 장소 | 얻는 것 |
|---|---|---|
| 상점 구매 | 마을 상점 | 낮은 등급 스킬 (하급·중급, 임시) |
| 특수 이벤트 | 던전 | 높은 등급 스킬 (상급·최상급, 임시) |
| 드롭 아이템 | 던전 | 높은 등급 스킬서 (상급·최상급, 임시) |
| 수련 | 마을 수련장 | 새 스킬이 아니라 보유 스킬 강화 (골드 소모) |

### 장착 슬롯

모험가 등급이 2단계 오를 때마다 장착 슬롯이 1개 늘어납니다.

| 모험가 등급 | 장착 슬롯 (임시) |
|---|---|
| F, E | 3 |
| D, C | 4 |
| B, A | 5 |
| S, SS | 6 |

스킬마다 장착 조건(레벨, 모험가 등급)이 있습니다.

## 마을

마을에는 수련장, 상점, 대장간, 길드가 있고 각 시설 화면 상단에 담당 NPC 일러스트가 표시됩니다. 창고는 길드 안에 둡니다.

### 시설

| 시설 | 기능 | 임시 수치 |
|---|---|---|
| 수련장 | 골드를 내고 보유 스킬 강화 | 200G × 다음 강화 단계 |
| 상점 | 하급·중급 스킬, 장비, 소모품, 가방 구매와 판매 | 장비 6칸 + 소모품·스킬 6칸 |
| 대장간 | 장비 강화 | 장비와 인벤토리 항목 참고 |
| 길드 | 퀘스트 수주·보상, 모험가 등급 확인·승급, 창고 | 동시 수주 3개 |

### 창고 (길드)

- 길드에 아이템을 맡기면 던전에서 사망해도 잃지 않습니다.
- 시작 4칸, 모험가 등급이 오를 때마다 2칸 추가 (v2.3, 최대 18칸). 이미 넘게 맡긴 물건은 유지하고 새로 맡기는 것만 막습니다.
- 인벤토리(가방)는 골드로, 창고는 모험가 등급으로 확장합니다.

### 상점 재고 갱신

- 자동 갱신은 없습니다 (v2.4). 골드를 내고 갱신할 때만 물건이 바뀝니다.
- 갱신 비용은 100G부터 갱신할 때마다 2배, 던전에서 돌아오면 100G로 초기화.

### 퀘스트

- 퀘스트마다 권장 모험가 등급과 목표 던전 층이 있습니다.
- 지금까지 클리어한 층과 지금 도전 가능한 층을 목표로 하는 퀘스트만 등장합니다.
- 자기 등급 기준 한 단계 아래부터 한 단계 위까지만 수주할 수 있습니다.
- 낮은 등급 퀘스트는 목표 층이 얕고 보상이 적어 손해가 되도록 설계합니다.

| 퀘스트 등급 | 보상 배율 (임시) |
|---|---|
| 자기 등급 −1 | × 0.5 |
| 자기 등급 | × 1.0 |
| 자기 등급 +1 | × 1.5 |

### 모험가 등급과 승급 조건

등급은 F부터 SS까지 8단계입니다. 승급하려면 돌파 층, 레벨, 퀘스트 완료 횟수 세 조건을 모두 충족해야 합니다. 레벨이 내려가지 않으므로 강등은 없습니다.

| 승급 | 1차 30층: 층 / 레벨 / 퀘스트 | 100층 확장 시: 층 / 레벨 / 퀘스트 | 배지 효과 |
|---|---|---|---|
| F (시작) | - | - | 없음 |
| F → E | 3 / 5 / 3 | 5 / 10 / 5 | +2% |
| E → D | 6 / 10 / 8 | 15 / 20 / 15 | +4% |
| D → C | 10 / 18 / 15 | 30 / 35 / 30 | +6% |
| C → B | 15 / 26 / 25 | 45 / 50 / 50 | +9% |
| B → A | 20 / 35 / 40 | 60 / 65 / 75 | +12% |
| A → S | 25 / 45 / 60 | 75 / 80 / 100 | +16% |
| S → SS | 28 / 55 / 80 | 90 / 90 / 130 | +20% |

- 100층 확장 시 값은 최대 레벨 100 기준입니다 (임시).
- 배지는 현재 등급의 배지 하나만 적용합니다.
- 배지 효과는 장비·버프를 제외한 캐릭터 자체 능력치에만 곱합니다.

## 던전

던전은 층마다 여러 방으로 이루어지며, 층에 도전할 때마다 방 배치와 내용이 새로 섞입니다. 보스를 잡으면 남은 방을 건너뛰고 다음 층으로 갈 수 있습니다.

### 층 구조

- 층당 방 8~12개 + 보스 방 1개 (임시).
- 도전할 때마다 방 배치가 랜덤으로 바뀌고, 방에 배정된 전투·이벤트·상인 등의 순서도 섞입니다.
- 한 번의 도전 중에는 클리어한 방이 다시 생기지 않습니다.
- 갈림길에서는 플레이어가 다음 방을 선택합니다.

### 층 테마와 몬스터 (임시)

판타지 계열 몬스터로 구성하며, 10층마다 테마가 바뀌고 10층 단위 마지막 층에 고유 보스가 나옵니다. 나머지 층의 보스는 그 테마 몬스터의 강화형입니다.

| 층 | 테마 | 일반 몬스터 | 고유 보스 |
|---|---|---|---|
| 1~10층 | 어두운 동굴 | 슬라임, 고블린, 고블린 궁수, 거대 박쥐, 큰 쥐, 거대 거미, 늑대 | 10층 고블린 왕 |
| 11~20층 | 버려진 묘지 | 오크, 스켈레톤, 좀비, 구울, 오크 주술사, 유령 | 20층 저승사자 |
| 21~30층 | 고대 유적 | 독버섯, 독사, 바위 거북, 도깨비불, 임프, 떠다니는 눈알 | 30층 고대 골렘 |

### 방 구성 규칙

| 방 종류 | 최소 | 최대 | 비고 (임시) |
|---|---|---|---|
| 전투 | 4 | 제한 없음 | 적 1~4마리 |
| 이벤트 | 1 | 제한 없음 |  |
| 보물 | 0 | 2 | 첫 보물 방은 65% 확률 (v2.3, 평균 약 0.75개) |
| 휴식 | 1 | 3 |  |
| 귀환 방 | 1 | 1 | 층마다 1개 고정 |
| 상인 | 0 | 1 | 등장 확률 60% |
| 보스 | 1 | 1 | 시작 지점에서 가장 먼 방 |

생성 순서 (임시):

1. 방 수를 정합니다 (보스 제외 8~12개).
2. 최소 개수부터 배치합니다: 전투 4, 이벤트 1, 휴식 1, 귀환 1 (보물은 65% 확률로 1개).
3. 상인을 60% 확률로 1개 추가합니다. 칸이 부족하면 방 수를 1 늘립니다.
4. 남은 칸은 가중치로 채웁니다: 전투 50, 이벤트 30, 보물 5, 휴식 10. 최대치에 도달한 종류는 제외합니다.

### 배치 형태

- 가지형, 순환형, 격자형 등 여러 패턴 중 하나를 랜덤으로 씁니다.
- 보스 방은 시작 지점에서 최단 경로로 가장 먼 방입니다.
- 직진만으로 보스 방에 닿지 않도록, 보스까지 가는 길에 갈림길 최소 2개와 막다른 가지 최소 1개를 둡니다 (임시).

### 미니맵과 이동

- 현재 층수와 탐험한 방을 표시합니다.
- 방을 클리어하면 다음에 갈 수 있는 방이 깜빡이며 선택을 기다립니다.
- 이미 탐험한 방과 발견한 귀환 방으로 텔레포트할 수 있습니다 (비용 없음, 전투 중 불가, 임시).
- 쉬움 난이도에서만 다음 방이 어떤 종류(전투·이벤트·보물 등)인지 미리 표시합니다.

### 귀환과 사망

| 상황 | 층 진행 | 골드·경험치 | 아이템 |
|---|---|---|---|
| 보스 클리어 후 귀환 | 다음 층 개방 | 유지 | 유지 |
| 귀환 방·특수 이벤트로 귀환 | 그 층 진행도 초기화 | 유지 | 유지 |
| 사망 (하드코어 제외) | 도달 층수 유지, 그 층 진행도 초기화 | 골드 −30%, 경험치 −20% (레벨 감소 없음, 임시) | 장착하지 않은 인벤토리 아이템 전부 손실. 창고 아이템과 가방 확장은 유지 |

## 전투

전투는 선택지 기반 턴제입니다. 공격, 스킬, 회복, 도망 등 게임 안의 모든 선택은 1턴을 소모하며, 설정·일시정지만 턴을 쓰지 않습니다.

### 기본 규칙

- 적의 수는 방마다 다르며 1마리 또는 여러 마리 (임시 1~4마리).
- 대상 선택은 공격 선택에 포함됩니다. 예: "고블린 A 공격", "고블린 B 공격"이 각각 하나의 선택지입니다.
- 선택지는 기본 공격, 장착 스킬, 아이템, 도주로 구성되며, 화면을 넘으면 스크롤합니다.
- 스킬은 사용 후 정해진 턴 동안 다시 쓸 수 없습니다.
- 각 선택지에는 성공 확률을 표시합니다.
- 성공률 = 기본 50% + (관련 능력치 − 요구치) × 5%, 최저 5%·최고 95% (임시).

### 버프·디버프 1차 목록

지속 턴은 스킬마다 다르게 정합니다. 패시브 성격의 효과도 버프로 처리합니다.

| 구분 | 이름 | 효과 (임시) |
|---|---|---|
| 버프 | 강화 | 공격력 +20% |
| 버프 | 철벽 | 받는 피해 −20% |
| 버프 | 재생 | 턴마다 최대 HP의 5% 회복 |
| 버프 | 집중 | 선택지 성공률 +10% |
| 버프 | 날렵함 | 회피 +15% |
| 디버프 | 독 | 턴마다 최대 HP의 4% 피해 |
| 디버프 | 출혈 | 행동할 때마다 고정 피해 |
| 디버프 | 화상 | 턴마다 피해, 받는 회복량 −50% |
| 디버프 | 약화 | 공격력 −20% |
| 디버프 | 취약 | 받는 피해 +20% |
| 디버프 | 기절 | 다음 1턴 행동 불가 |
| 디버프 | 침묵 | 스킬 사용 불가 |
| 디버프 | 실명 | 성공률 −15% |
| 디버프 | 공포 | 도주 외 선택지 성공률 −10% |

### 중첩 규칙

1. 서로 다른 버프·디버프는 함께 적용됩니다.
2. 같은 효과·같은 수치가 다시 걸리면 남은 턴이 더 긴 쪽으로 대체됩니다.
3. 같은 효과인데 수치가 다르면 가장 높은 수치만 적용됩니다. 높은 쪽이 먼저 끝나면, 남은 턴이 있는 낮은 쪽이 이어서 적용됩니다.
4. 같은 효과·같은 남은 턴이면 나중에 건 쪽이 남습니다.

## 장비와 인벤토리

### 장비 슬롯 (8칸)

| 분류 | 슬롯 |
|---|---|
| 방어구 (4) | 투구, 갑옷, 바지, 신발 |
| 장신구 (3) | 목걸이, 반지 1, 반지 2 |
| 무기 (1) | 무기 1개 (검·활·단검·지팡이 등 모두 한손 무기로 취급) |

디아블로 IV의 방어구 5개·장신구 3개·무기 구성 (출처)에서 장갑과 보조무기를 뺀 구성입니다.

장비 슬롯은 8칸이며 모든 무기는 한손 무기로 취급해 1칸만 차지합니다. 장비에는 랜덤 옵션이 없고 기본 수치와 착용 제한만 있습니다. 인벤토리는 탭 없이 세로 화면에 맞춘 5열 격자이고, 가방을 사야 칸이 늘어납니다.

### 장비 정보

| 항목 | 내용 |
|---|---|
| 이름 | 예: 낡은 단검 |
| 등급 | 일반~전설 (기본 수치의 크기만 다름) |
| 기본 수치 | 무기는 공격력, 방어구는 방어력, 장신구는 능력치 고정 보너스 |
| 레벨 제한 | 착용 가능한 최소 레벨 |
| 직업 제한 | 무기는 직업 전용 (전사 검·도끼, 궁수 활, 도적 단검, 마법사 지팡이). 방어구·장신구는 공용 |
| 강화 단계 | +0 ~ +10 (대장간) |

### 아이템 등급 (1차 30층: 5단계)

| 등급 | 색 | 첫 등장 층 (임시) | 획득 경로 (임시) |
|---|---|---|---|
| 일반 | 흰색 | 1층 | 상점, 일반 드롭 |
| 고급 | 초록 | 1층 | 상점, 일반 드롭 |
| 희귀 | 파랑 | 5층 | 드롭, 퀘스트 |
| 영웅 | 보라 | 12층 | 엘리트·보스 드롭, 특수 이벤트 |
| 전설 | 주황 | 20층 | 보스 저확률 드롭 |

층을 늘릴 때 등급도 함께 늘립니다: 50층 6단계(+유물), 100층 7단계(+고대).

### 인벤토리

- 탭 구분 없이 장비·소모품·재료를 한 칸에 하나씩 넣습니다.
- 세로 화면 기준 5열 고정, 세로 스크롤 (임시).
- 360dp 폭 화면에서 5열이면 칸당 약 64dp로, 손가락으로 누르기에 충분한 크기입니다.
- 시작 20칸 (5 × 4). 가방 1개를 살 때마다 1줄(5칸) 추가, 최대 60칸 (5 × 12) (임시).
- 가방 가격: 500G부터 구매할 때마다 2배 (임시).

### 장비 강화 (대장간)

| 강화 단계 | 성공률 (임시) | 실패 시 |
|---|---|---|
| +1 ~ +5 | 100% | - |
| +6 ~ +8 | 70% → 50% | 재료·골드만 소모 |
| +9 ~ +10 | 30% → 15% | 재료·골드만 소모 |

- 강화 1단계마다 장비 기본 수치 +5% (임시).
- 장비 파괴는 없음 (임시).

## 난이도와 저장

밸런싱은 보통 난이도를 기준으로 하고, 다른 난이도는 적 능력치에 배율을 곱해 조절합니다. 쉬움만 다음 방 정보를 미리 보여줍니다.

| 난이도 | 적 HP·공격력 (임시) | 다음 방 정보 | 사망 시 |
|---|---|---|---|
| 쉬움 | × 0.75 | 표시 | 골드·경험치 감소, 미장착 아이템 손실 |
| 보통 | × 1.0 (기준) | 숨김 | 골드·경험치 감소, 미장착 아이템 손실 |
| 어려움 | × 1.25 | 숨김 | 골드·경험치 감소, 미장착 아이템 손실 |
| 하드코어 | × 1.25 | 숨김 | 캐릭터 초기화 |

자동 저장 방식은 플레이 테스트 후 결정합니다.

## 화면 구성 (UI)

세로 모바일 화면(390 × 844 기준) 11개로 구성합니다. 일러스트는 마을 시설과 특수 이벤트에만 쓰고, 던전 탐험·전투는 텍스트와 기본 도형만 씁니다. 시안: 모험가 키우기 UI 시안

### 화면 목록

| 화면 | 일러스트 | 주요 구성 |
|---|---|---|
| 새 게임 | 없음 | 난이도 4종, 직업 4종(변경 불가 안내), 이름 입력, 모험 시작 |
| 마을 | 마을 전경 (선택) | 상단 상태(이름·레벨·경험치·등급·골드), 시설 4개, 던전 입장 버튼, 하단 메뉴 |
| 시설 공통 (길드 예시) | 상단 NPC | 상단 일러스트 + 대사 상자, 탭(퀘스트·등급·창고), 목록 |
| 상점 | 상단 NPC | 유료 갱신, 장비 6칸, 소모품·스킬서·가방 |
| 캐릭터 | 없음 | 경험치, 배지·승급 진행, 능력치 5개(+ 버튼), 자동 배분, 상세 보기 |
| 가방·장비 | 없음 | 장비 8칸, 5열 가방 격자, 선택 아이템 정보(착용·판매), 사망 손실 안내 |
| 스킬 | 없음 | 장착 슬롯, 보유 스킬(재사용 턴·장착 조건), 장착·해제 |

### 화면 흐름

새 게임 → 마을 ↔ (길드·상점·대장간·수련장 / 캐릭터·가방·스킬) → 던전 탐험 ↔ (전투·특수 이벤트) → 귀환 정산 또는 사망 정산 → 마을

### 공통 규칙

- 마을 계열 화면은 하단 메뉴(마을·캐릭터·가방·스킬·설정)로 이동합니다.
- 던전 계열 화면에는 하단 메뉴 대신 일시정지 버튼을 둡니다.
- 버튼과 선택지의 최소 높이는 44px 이상입니다.
- 장비 등급은 색으로 구분합니다: 일반 흰색, 고급 초록, 희귀 파랑, 영웅 보라, 전설 주황.
